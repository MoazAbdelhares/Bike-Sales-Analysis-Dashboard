 Project Overview
This project presents an interactive Excel Dashboard designed to analyze customer demographics and purchasing behavior for a bike retail business. By examining variables such as age, income, and commute distance, this dashboard helps identify the core customer base and sales trends.

 Key Insights
Age Demographics: The "Middle Age" bracket represents the peak segment for bike purchases, significantly outperforming adolescents and seniors.

Income & Gender: Customers who purchased bikes generally have a higher average income. On average, male customers have both higher income levels and higher purchase rates than females.

Commute Distance: The highest conversion rate is among customers with a short commute (0-1 miles). Sales drop sharply as the commute distance exceeds 10 miles.

Car Ownership: Interestingly, customers owning 2 cars show the highest volume of purchases, while those with 3 or more cars are the least likely to buy.

 Technical Features
Data Cleaning: Handled missing values and categorized age groups.

Pivot Tables: Used to aggregate data for specific metrics (Income, Commute, Age).

Interactive Slicers: Allows users to filter the entire dashboard by Marital Status, Region, and Education level.

 How to Use
Download the .xlsx file from this repository.

Open the file in Microsoft Excel.

Use the Slicers on the left to interact with the charts and discover specific regional or educational trends.

لوحة تحليل مبيعات الدراجات
 نظرة عامة على المشروع
يقدم هذا المشروع لوحة بيانات تفاعلية (Excel) تم تصميمها لتحليل البيانات الديموغرافية للعملاء وسلوكهم الشرائي في قطاع بيع الدراجات. من خلال فحص متغيرات مثل العمر، الدخل، ومسافة التنقل، تساعد هذه اللوحة في تحديد قاعدة العملاء الرئيسية واتجاهات المبيعات.

 أهم النتائج والتحليلات
الفئات العمرية: تمثل فئة "متوسطي العمر" الشريحة الأكبر في شراء الدراجات، متفوقة بشكل كبير على فئتي المراهقين وكبار السن.

الدخل والنوع الاجتماعي: العملاء الذين اشتروا دراجات يمتلكون عموماً متوسط دخل أعلى. وبشكل عام، أظهر الذكور مستويات دخل ومعدلات شراء أعلى من الإناث.

مسافة التنقل: أعلى معدل شراء يتركز لدى العملاء الذين يقطعون مسافات قصيرة (0-1 ميل). تنخفض المبيعات بشكل حاد عندما تتجاوز مسافة التنقل 10 أميال.

ملكية السيارات: من المثير للاهتمام أن العملاء الذين يمتلكون سيارتين سجلوا أعلى حجم مشتريات، بينما كان أصحاب الـ 3 سيارات أو أكثر الأقل إقبالاً.

 الميزات التقنية
تنظيف البيانات: معالجة القيم المفقودة وتصنيف الفئات العمرية بشكل منطقي.

الجداول المحورية (Pivot Tables): تلخيص البيانات لحساب المقاييس الأساسية (الدخل، التنقل، العمر).

أدوات التصفية التفاعلية (Slicers): تسمح للمستخدم بفلترة لوحة البيانات بالكامل حسب الحالة الاجتماعية، المنطقة، والمستوى التعليمي.
